# Silvana Lanches — Modo Fábrica

Cardápio digital criado em modo fábrica.

## Estado atual
- 52 itens em 8 categorias.
- Catálogo baseado no vídeo do `pedir.delivery` fornecido durante o projeto.
- Visual inspirado na direção do projeto Torre de Pizza.
- QA funcional desktop/mobile aprovado.
- WhatsApp público temporariamente desativado até a configuração do número definitivo.
- Nenhuma mensagem é enviada automaticamente: quando habilitado, o site apenas abre o WhatsApp com o texto preenchido.

## Publicação
- Repositório: `rhenanjogafacil123/silvana-lanches`
- Deploy Vercel criado para validação pública.

## Pendências opcionais antes de uso comercial
1. Configurar o WhatsApp definitivo.
2. Confirmar horário de funcionamento.
3. Conferir opções internas de produtos marcados como “A partir de”.
4. Adicionar imagens reais dos produtos quando desejado.
